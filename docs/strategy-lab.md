# V3 策略实验室

## 范围

首版实验室只允许基于 `course49_v3` 生成兼容变体。模型可以改写候选准入、交易模式、排序得分和目标仓位 hook，不能覆盖数据读取、`scan`、数据库、持久化、TDX 回传或订单逻辑。

## 生命周期

1. 用户提交自然语言假设和一个已完成的 V3 基准回测 ID。
2. 模型生成继承 V3 基类的实验源码和变更摘要。
3. 源码写入 `data/strategy_lab/experiments/<experiment_id>/`，不修改正式源码，也不在 FastAPI 进程内导入。
4. AST 校验后，在清除密钥的独立子进程中执行契约、防未来、超时和内存检查。
5. 候选从基准不可变快照回放，并使用相同快照执行双倍成本压力测试。
6. 页面展示源码差异、测试、基准、候选、压力结果和统计验证状态。
7. 只有代码与比较门槛通过后才允许人工晋级到 `data/strategy_lab/promoted/`。

## 代码约束

生成模块只能导入批准的数学、类型和策略契约模块，只能定义一个 V3 变体类并覆盖批准 hook。禁止文件、网络、进程、动态导入、反射、`open`、`eval`、`exec`、`compile`、`__import__` 和 dunder 属性访问。

该隔离用于约束本地可信模型输出，不是可抵御恶意 Python 的操作系统安全沙箱。服务进程永远不直接执行未验证源码。

## 比较与晋级

默认门槛为：所有校验通过、同快照成功回放、总收益不低于基准、最大回撤恶化不超过 1 个百分点、双倍成本收益为正。250 日、30 笔平仓、四段切片、冻结后 60 日和 10 笔平仓仍按正式 V3 验证协议单独报告。

晋级版本仅进入本地实验策略目录，状态为“可回测、禁止扫描”。它不会替换 `course49_v3`、不会加入默认组合，首版也不提供启用扫描接口。

## 接口

- `POST /api/research/experiments`：生成并验证实验。
- `GET /api/research/experiments` 与 `GET /api/research/experiments/{id}`：查询实验和产物。
- `POST /api/research/experiments/{id}/promote`：人工晋级已通过门槛的实验。
