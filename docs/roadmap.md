# 路线图

## V1 已落地

- TDX 主数据源、标准字段与数据健康门槛。
- 缠论和 49 课两个独立策略插件。
- Python 回测、模拟组合、人工审批和 Web 工作台。
- SQLite 研究记录、Parquet 快照与显式 TDX 回传。

## V1.1 已落地

- 49课市场周期、题材生命周期、龙头角色与动态仓位。
- 通达信龙虎榜聚合资金接入、事件快照和防未来截断。
- 信号页展示市场阶段、题材阶段、龙头角色与资金结构。

## V1.2 已落地

- 通达信全市场涨跌、涨跌停、连板、回封率与封板资金生态历史。
- 个股历史首封、开板、封单、竞价强度、首板成功率和次日溢价行为评分。
- 49课资金/封板双确认、晚封弱封否决、动态仓位与回测确认因子归因。
- 市场生态、涨停行为和龙虎榜独立快照及防未来测试。

## V2.0 已落地

- `course49_v1` 1.2 保持基线，新增 `course49_v2` 2.0 与同快照 A/B 回测。
- 中证300/1000/创业板风格分类、三种短线交易模式、动态风险预算。
- 连续两日市场/题材/龙头滞回、追踪止盈及模拟运行状态持久化。
- 全 A 默认不截断，固定种子分层抽样、股票池哈希和实际分布。
- 逐日风格状态、交易证据、板块成分快照与可信度标记。

## V3.0 已落地

- 策略插件元数据与强类型数据需求，页面可检查来源、频率、复权和回看长度。
- 可持久化策略组合：资金分舱、信号加权、交集确认、风险覆盖和对照实验。
- `pairs_arbitrage_v1` 多腿价差策略、人工整组审批、原子模拟成交和多空权益核算。
- Schema V7 多腿意图、交易腿、决策、持仓、成交、插件来源、运行适配器与回测归属字段。
- 策略实验室、动态回测选择、组合持仓与配对敞口/盈亏指标。

## 49课 V3 实验版已落地

- `course49_v3` 局部加速核心规则、独立模拟账户及 `course49_v3_compare` 同快照对照。
- 全市场市场阶段特征矩阵，避免按日重复计算生态特征。
- 可执行事件诊断命令，分解市场阶段、连板高度、涨停制度与 1/3/5 日扣费收益。
- 5,100 只全 A、28 日正式 V3 回测耗时 592 秒，满足 20 分钟性能验收；结果仍属发现窗口，不作为收益达标证明。
- V3 保持实验状态；完成 250 日以上全市场与滚动样本外验证前，不进入默认组合。

## 49课 V4/V5 历史验证已落地

- 247 日全 A 长窗口反证 V3：总收益 -6.50%、最大回撤 -25.82%，保留失败基线。
- V4 将龙虎榜净买比例至少 5% 设为硬准入，限制二至四板并排除不适配风格；同快照总收益 17.85%、最大回撤 -10.96%。
- V5 仅把 V4 基础风险预算从 22% 提至 25%；252 日历史总收益 20.13%、年化 20.22%、最大回撤 -12.11%。
- V5 双倍执行成本回放总收益 17.62%；不可变快照、内容哈希校验、分段收益和正式验证门禁已贯通。
- V5 只允许回测，默认扫描和组合仍使用 V2；冻结日之后样本外数据不足，正式状态为 `UNVERIFIED`。

## 49课 V6 奖励策略实验已落地

- 发现并修复 V5 首板诊断的未来连板筛选偏差；快照新增最低连板覆盖数，不兼容回放会被拒绝。
- V6 6.3 聚焦小盘投机加速期的 0.55-0.70 质量首板，五日退出、3% 止损，仅允许回测。
- 两个非重叠全 A 窗口年化分别为 29.78% 和 38.14%，双倍成本后仍高于 20%。
- 收益集中度、近期收益中位数和平仓样本数未通过正式门禁，状态保持 `UNVERIFIED`，不替换 V2。
- 事件对象过滤无关普通日期，全首板窗口峰值工作集由超过 2.5GB 降至约 0.9GB。

## 49课 V7-V9 第二奖励模式已落地

- 修正事件诊断退出口径：摘要使用观察持有日后的下一开盘成交，同时保留收盘事件研究字段。
- V7 发现全面风险偏好下的首板反复开板回封模式；V8 用入场日前十日龙虎榜状态排除资金拥挤。
- V9 将封板质量冻结在 0.50-0.55，实际单票目标24%、最多三只，并保留3%固定止损和三日退出。
- 两个规则发现窗口年化 29.32%/50.57%，42/45 笔平仓，中位数与剔除前三赢家后的收益均为正；近期双倍成本年化44.25%。
- 冻结后首次读取的 2023-06 至 2024-06 真正历史留出集年化 -2.55%、25笔平仓，否决跨周期稳健性；V9 标记为 `HISTORICAL_REJECTED`，不替换V2。

## 49课 V10-V11 市场奖励边界

- V10 用三日市场生态动量过滤 V9，修复 2023-2024 亏损窗口，但 2022-2023 未见窗口年化仅2.50%，标记为 `HOLDOUT_TARGET_REJECTED`。
- V11 改用至少三次开板后回封，四个形成窗口全部为正；五日持有在弱窗口降低收益并扩大回撤，因此保留三日退出。
- 规则冻结后的第五个独立窗口年化 8.41%，双倍成本年化 5.94%，但中位交易为负、剔除前三大赢家后转亏且多数时间折不盈利；标记为 `HISTORICAL_ROBUSTNESS_REJECTED`。
- 下一阶段不继续围绕 V11 微调阈值。20% 年化改为组合目标：保留 49 课强势情绪分舱，并研发与其低相关、能够覆盖混合及防御风格的独立策略。
- 20% 年化改为多策略组合研究目标；单个 49 课子策略必须先满足跨周期正期望和可解释风险边界，不以加仓掩盖低频问题。

## V3.1 大模型研究闭环

- OpenAI 结构化日报、候选证据意见和模型调用审计。
- 带理由、置信度和风险预算的人工审批，以及实际模拟/拒绝反事实反馈。
- `course49_v3` 隔离代码生成、AST 校验、子进程测试、同快照回放和双倍成本比较。
- 人工晋级的本地实验策略仅可回测，禁止扫描、自动批准和默认组合替换。

## V3.2 插件与通用执行基础设施

- `strategy_plugins/` 清单式动态发现、API V1 契约校验、错误隔离和 Web 热重载。
- `generic_daily` 同时支持普通单腿信号与原子多腿意图，统一执行次日开盘、T+1、涨跌停、费用和滑点。
- 策略目录展示插件来源、适配器、能力和加载问题；禁用成员不能通过组合间接运行。
- 组合角色、资产兼容性和冲突政策完成后端校验，`priority`、`net_score`、`risk_first` 具有明确执行语义。

## V3.3 无 GPU 性能基础设施

- 策略声明合并为 `DataPlan`，固定股票策略不再加载全市场，历史读取严格使用截止日期和 90 根预热。
- Schema V8 数据缓存索引、原子快照发布、区间覆盖匹配、single-flight、24GB 内存 LRU 与 50GB 保护式治理。
- 行情 800 只、专业事件 500 只自适应批量；TQ 单通道，本地标准化使用 8 线程，最多三个快照作业并行。
- Course49 市场、资格、候选和版本特征跨对比实验复用；页面展示阶段、命中类型、数据时点、耗时和资源。

## 后续建议

- 为最新交易日增加增量追加，避免刷新时重建整个日线快照。
- 增加通用策略参数 Schema 与页面化版本对比；数据快照哈希和回测对比已经落地。
- 引入交易日历、复权因子和公司行动的独立校验。
- 加入 walk-forward、横截面分组和容量/冲击成本分析。
- 自 `2026-08-10` 起积累所有新奖励假设的冻结后样本；V6/V9 作为失败基线，不再围绕其阈值继续调参。
- 建立历史板块成分与逐秒炸板过程快照，消除49课长期回测的静态成分和路径缺口。
- 增加席位名称标准化及滚动胜率画像，但必须先建立按发布日期保存的历史明细库。

## 平台扩展方向

- 外部数据源注册机制，先支持 FRED/Fed 数据及发布日期防未来处理。
- 美股统一证券主数据、币种、交易日历和公司行动。
- 为信号融合、交集和风险覆盖实现逐日历史组合器；在完成前保持仅扫描限制。
- 增加滚动协整检验、配对发现、借券可用性、保证金和融券成本模型。
- 通达信 Lambda 交叉验证、可选本地调度和研究报告导出。

真实交易连接、云部署和多人权限必须经过独立的安全与风控设计，不作为现阶段自然延伸。
