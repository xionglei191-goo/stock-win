# 早期强势股识别 V1

## 项目边界

`early_winner_v1` 是一级分类 `research_project` 下的研究项目，生命周期永久为
`RESEARCH_ONLY`。项目包含两个互不融合的研究方法：

- `early_winner_rule_v1`：规则多因子 Top20。
- `early_winner_ml_v1`：固定参数 `HistGradientBoostingClassifier` 概率 Top20。

两个方法只写候选榜和审计记录，不产生 `BUY/SELL`，不创建或修改模拟账户，不推送
通达信，也不提供审批或实盘入口。项目状态只能在 `DATA_BUILDING`、`VALIDATING`、
`OBSERVATION_ONLY`、`BLOCKED_DATA` 和 `VALIDATION_REJECTED` 之间变化；验证通过也不会
自动转成正式策略。

## 数据门禁与时点

数据更新先对本机通达信 17709 HTTP 接口以及巨潮资讯公开公告、行业变更接口做字段
准入。财务、资金和一致预期请求必须返回固定字段契约；依赖缺失、客户端未运行、字段
漂移、覆盖率不足或文件哈希不一致都会失败关闭。系统不做静默字段替代。

通达信安装来源既可以是 Windows 注册表，也可以是显式配置的 `TDX_ROOT`。便携目录必须
同时包含 `TdxW.exe` 和 `PYPlugins/user`，并且正在运行的进程路径必须与该目录一致；当前
默认目录为 `D:\Project\stock\tdx-mock`。

巨潮数据由平台直接调用 `www.cninfo.com.cn` 和 `webapi.cninfo.com.cn`，不经过 AKShare，
不需要巨潮账号或付费 Token。公告查询保存官方原文 PDF 链接、公告 ID、机构 ID、发布
时间和原始响应哈希；只有日期而没有时分秒的公告按当日收盘后生效。行业接口只接受
巨潮新/旧分类标准（`008002/008013`）的连续历史，保存完整层级、生效日期和原始响应
哈希，禁止在同一横截面混用其他行业标准。

特征使用前复权行情，执行结果使用未复权行情。财务、公告和行业归属只允许在
`published_at/effective_at <= 决策日收盘` 时连接；15:00 后公告最早下一交易日可用。
一致预期从项目上线后逐日保存，`history_policy=FORWARD_ONLY`，禁止用当前值回填历史。
历史标签只能使用当时已披露的业绩预告、快报及未来 60 个交易日未复权执行收益。

原始行情、财务、资金、公告、行业和一致预期文件写入 `data/` 下的研究运行目录，不进入
Git。SQLite 的 `research_data_batches` 只保存路径、来源、行数、内容哈希、模式哈希和
审计元数据。

历史构建是独立、可断点续跑的年度分片任务。它冻结 2018–2025 每周最后交易日横截面、
沪深一致的版本化交易日历、字段模式及未来 60 个交易日未复权执行结果；财务覆盖率低于
85%、行业覆盖率低于 90%、沪深日历不一致或任一分片哈希损坏时，整批失败关闭。普通
`refresh` 只更新最新一期，不再隐式触发历史回填。巨潮年度公告进一步按固定股票代码组
冻结，每组保存代码哈希、文件哈希和日期边界；中断后只重取未完成组。TDX 与巨潮只读
请求均采用有限退避重试，重试耗尽后仍失败关闭，不做静默替代。

## 排名和模型

共同股票池要求上市至少 120 个交易日、近 20 日至少 18 个有效交易日、20 日平均成交额
不低于 1 亿元，并排除 ST、退市整理、停牌和数据不足股票。规则模型额外执行基本面、
行业、RS60、突破和过热硬门槛；行业、基本面、动量、突破、事件和资金的权重分别为
25%/20%/20%/15%/10%/10%。60 日前高点使用 `rolling(60).max().shift(1)`。

ML 仅使用规则模型的点时因子和相应缺失标识。参数、特征顺序和随机种子 49 固定。
滚动冻结窗口为 2018–2022/2023/2024 和 2019–2023/2024/2025，训练末端清洗 60 个
工作日，验证与测试开头隔离 20 个工作日；2026 数据不参与首次训练。模型记录保存训练
窗口、Python/NumPy/pandas/scikit-learn 版本、参数、特征模式哈希和模型文件哈希。

规则、ML 和纯 RS60 基准都按同一日期、同一不可变特征快照评估。每榜最多 20 只、每个
行业最多 5 只，不足部分保留现金。

## 执行与验证

历史结果按周末收盘决策、下一交易日开盘执行。研究执行函数实现 T+1、一字涨停禁买、
一字跌停延迟卖出、单票 5% 上限和单次委托不超过 ADV20 的 2%。固定 60 日结果以未复权
开盘价计算；组合验证另计基础和双倍成本、换手率、最大回撤、Sharpe、Calmar、IC、
PR-AUC、Precision@20，并报告剔除收益最高 5 个持仓样本后的结果。

60 日组合收益采用非重叠资金周期：一个候选批次建仓后，下一批纳入组合收益的候选日
必须晚于该批次退出日；精确率、IC 和 PR-AUC 仍按全部周度样本计算。这样可以避免把同一笔
资金在重叠的 60 日持有期内重复复利。规则、ML 和 RS60 使用完全相同的周期选择逻辑。

只有规则或 ML 在 2024、2025 两个冻结测试期均同时满足以下条件，项目才进入
`OBSERVATION_ONLY`：组合收益优于纯 RS60、双倍成本收益仍优于纯 RS60、
Precision@20 更高，且最大回撤不比基准差超过 3 个百分点。否则保存完整结果并标记
`VALIDATION_REJECTED`。

验证记录只允许一个 `champion`。仅规则通过时选规则，仅 ML 通过时选 ML；两者均通过仍
固定选规则，两者均失败则冠军为空。冠军记录冻结规则/模型文件哈希、特征哈希、验证 ID
和数据快照 ID，之后的任何规则、特征或依赖变更必须另建 V2。

## 首次冻结验证结果（2026-08-12）

历史任务 `history-75981a3a7bd7495f740b81fa` 已成功冻结 2018—2025 共 337,416 条
点时特征，快照为 `ewfs_9f8b1a5e0e1b805c400a176ea81008ba`。固定种子 49 的模型版本为
`ewm_ad32929172da4c43a808abc6996b35e3`，模型文件哈希为
`463ec1e4d48192276a73f3ee8dfb34b446ab3c9f06e41b95daa4d7203983954e`。

最终有效验证 `ewv_2909ff9f38d949b1addfef53c07f145c` 的结论为
`VALIDATION_REJECTED`：规则法只通过 2024 冻结期、未通过 2025；ML 只通过 2025、
未通过 2024。因此没有 `champion`，交易部署保持 `VALIDATION_REQUIRED`，影子、仿真和
实盘均不得启动。该结果是既定停止门禁，不允许在 2024/2025 测试集上继续调参。

审计中发现的两次中间验证分别存在重叠 60 日收益复利和使用最终模型代替逐年样本外模型
的问题，相关记录已标记 `SUPERSEDED_INVALID_METRICS`；缺少逐年样本外模型的旧模型也已
标记 `SUPERSEDED_INCOMPLETE_OOS`，均不参与项目状态或冠军选择。

## API 与页面

- `GET /api/research/early-winner`
- `GET /api/research/early-winner/candidates?method=rule|ml&asof=YYYY-MM-DD`
- `POST /api/research/early-winner/refresh`
- `POST /api/research/early-winner/train`
- `POST /api/research/early-winner/validate`
- `POST /api/research/early-winner/history/build`
- `GET /api/research/early-winner/history/status`

四个写操作共享 `early_winner_project` 任务互斥键；已有任务处于 `QUEUED/RUNNING` 时返回
当前任务 ID。页面路由为 `/research/early-winner`，只提供更新数据、训练模型和运行验证。

## 交易部署边界

当前仓库构建固定为研究与模拟盘模式。后端不挂载 `/api/trading/*`，前端没有真实交易
路由或操作控件，TDX 写入传输也未编译；环境变量不能重新开启券商下单或撤单。
`early_winner_trade_v1` 的历史部署设计仅保留为研究代码，不构成可运行的真实交易入口。

## 本机启动前检查

1. 安装项目固定范围依赖，确保 `cryptography>=44,<47` 和 `scikit-learn>=1.5,<2`。
2. 启动并登录支持的通达信客户端，确认本地 17709 服务可用。
3. 首次点击“更新数据”，检查页面上的 TDX、巨潮、点时和覆盖率门禁。
4. 在未形成完整 2018–2025 点时历史前，训练和验证保持 `BLOCKED_DATA` 是预期行为。
