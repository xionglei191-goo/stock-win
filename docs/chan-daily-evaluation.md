# 缠论日线策略首轮评估

## 结论

`chan_v1` 2.0.0 的五段冻结历史审计结论为 `HISTORICAL_REJECTED`。标准成本和双倍成本均为 0/5 个盈利窗口，跨窗口链式收益分别为 -43.67% 和 -48.10%。策略已关闭扫描和模拟新开仓，只保留回测复现；包含它的 `combined` 3.1.0 也改为历史比较组合。默认扫描、日报与回测入口切换为 `course49_system`。

结构信号使用前复权日线，成交与涨跌停判断使用不复权日线；信号在收盘后确认，订单在下一交易日开盘执行。审计同时修正了三个旧回放缺陷：股票资格改为每个历史日点时计算，输入严格限制为声明的 120 根预热，单笔净盈亏同时扣除买入和卖出费用。旧回放和下方首轮参数探索不再具备生命周期决策效力。

标准成本共完成 121 笔平仓，单笔净盈亏中位数为 -398.15 元，剔除前三大赢家后的净盈亏为 -35,450.13 元；最差压力窗口收益 -22.44%，最大窗口回撤 28.84%。同快照、同股票池成本复放门槛通过，但盈利窗口、链式收益、单笔中位数、收益集中度、最大回撤和最差窗口门槛全部失败。

冻结协议、断点运行清单和审计结果分别保存在 `data/research/chan_v1/protocol.json`、`run_manifest.json` 与 `historical_validation.json`。可用 `py -3 -m research_platform chan-study` 复算，并由 `GET /api/research/chan/validation` 查询。该研究为回顾性审计，且板块成员来自 `LIMITED/current_fallback`，即使历史门槛通过也不能授权晋级。

## 早期探索数据与口径

- 数据快照：本地通达信日线快照，截止 2026-08-07。
- 评估区间：2026-05-01 至 2026-08-07，共 60 个交易日。
- 执行：下一交易日开盘，含 T+1、涨跌停、佣金、最低佣金、印花税和 0.1% 滑点。
- 资金：50,000 元，最多 3 只，单股不超过策略资金 40%。
- 股票池：固定分层样本；板块成员使用当前快照，存在历史成分偏差。

## 后续研究前提

1. 不在这五个已读窗口上删除亏损交易、修改阈值或重定义门槛。
2. 先保存历史板块成分和可交易股票状态，消除当前成分回放历史的偏差。
3. 若提出 V2，先冻结与 V1 有明确机制差异的假设、参数、成本和失败门槛，再开启全新独立窗口。
4. 新版本仍需报告基准超额收益、资金利用率、持仓期归因和收益集中度，不能以提高仓位掩盖负期望。

当前合理表述是“Chan V1 已被五段历史审计否决”，而不是把早期 6.84% 样本内结果视为可复现收益。
