# 配对套利 V1 历史审计

## 结论

`pairs_arbitrage_v1` 1.0.0 的五段冻结回顾性审计结论为 `HISTORICAL_REJECTED`。标准成本只有 2/5 个窗口盈利，双倍成本只有 1/5 个窗口盈利；跨窗口链式总收益分别为 -6.99% 和 -12.49%。它不满足正期望的最低前提，因此不再继续评估作为低相关组合分舱的价值。

策略已关闭扫描和模拟新开仓，只保留回测复现。包含 40% 配对套利分舱的 `adaptive_multi_strategy` 也改为历史比较组合，不再支持扫描。审计产物为 `data/research/pairs_arbitrage_v1/historical_validation.json`，可通过以下命令重算，并由 `GET /api/research/pairs-arbitrage/validation` 查询：

```powershell
py -3 -m research_platform pairs-arbitrage-study
```

## 冻结规则

- 固定股票对：招商银行/兴业银行、中国平安/中国人寿。
- 最近 60 个交易日对数价格回归得到价差和 z-score。
- 收益相关性至少 0.70；`2.0 <= |z| < 3.5` 开仓，`|z| <= 0.5` 均值回归退出，`|z| >= 3.5` 发散止损。
- 总目标敞口 40%，收盘生成整组意图，下一交易日两腿原子开盘成交。
- 每段标准成本与双倍佣金、印花税、滑点使用同一不可变快照和相同固定股票池哈希。
- 五段共完成 53 组交易。门槛要求标准成本至少 4/5 段为正、双倍成本至少 3/5 段为正、两种链式收益均为正、单组盈亏中位数为正、剔除前三大赢家后仍为正。

本次是在全部窗口已经可见后建立的回顾性冻结审计，只能用于否决或保留研究基线，不能作为晋级证据。即便历史门槛全部通过，也必须再使用未参与规则和门槛形成的新独立窗口。

## 方法限制

V1 使用当前固定股票对，不是按历史时点可得信息发现的股票对，无法代表可扩展的配对选择流程。相关性只描述共同波动，不保证价差残差平稳，也不等同于协整关系。

信号计算会记录滚动回归的 `hedge_ratio`，但执行器按两腿各 50% 的 `target_weight` 分配资金；腿上的比率字段没有改变实际资金权重。因此 V1 的实际组合是等金额多空，不是滚动 beta 中性组合。

做空仅为纸面模拟，未建模融券标的历史可用性、借券费率、保证金、强制平仓和召回。现有结果在省略这些现实摩擦后仍为负，不能据此主张实盘可行。

## 后续边界

不在这五段已读窗口上删除亏损股票对、修改 z-score 或相关性阈值后重新宣称样本外有效。未来 V2 若继续，应先形成并冻结以下协议：历史时点配对发现；滚动残差平稳性或协整检验；真实进入仓位的对冲比率；行业和单股集中度上限；借券、保证金和冲击成本；至少五段新的非重叠独立窗口。只有正期望与成本稳健性先成立，才有必要测量它与 49 课、缠论的相关性和组合贡献。
